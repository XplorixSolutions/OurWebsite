# Xplorix Solutions — Comprehensive Image Generation Guide & Prompts

This document provides a complete inventory and detailed image generation prompts for all images used across the **Xplorix Solutions** web application. 

Every prompt is engineered to maintain consistent brand aesthetics, color harmony, and visual language matching the studio's ultra-premium cyber-editorial theme.

---

## 🎨 Global Theme & Aesthetic Guidelines

To maintain visual cohesion across the entire web application, all generated images should strictly adhere to the following artistic rules:

- **Color Palette**:
  - **Primary Background & Accents**: Deep Dark Burgundy / Bean (`#2E0D14`, `#1B080D`, `#120508`)
  - **Secondary Light & Metallic**: Warm Almond / Cream (`#EFE1D5`, `#D9C3B0`, `#FFF5ED`)
  - **Subtle Highlights**: Translucent glass, soft warm amber glow, polished obsidian, brushed bronze/rose gold metallic accents.
- **Lighting & Atmosphere**: Cinematic moody studio lighting, soft volumetric ambient glow, sharp rim highlights, translucent glassmorphism with refraction.
- **Visual Style**: Modern 3D Octane / Redshift visual art, editorial minimalism, cyber-tech abstract geometry, high-precision UI telemetry elements.
- **Aspect Ratios & Output**: 
  - Hero Artwork: `1:1` or `4:3` PNG with transparent background (or dark backdrop cut-out).
  - Cards & Backgrounds: `16:9` or `4:3` high resolution (8K detail, photorealistic rendering).
